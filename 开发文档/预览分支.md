# 下游预览分支

仓库：`qbmzc/FeiNiuMusic`；持续集成分支：`preview`。
此分支基于上游 1.6.8，在下游集中验证尚未全部合并的改动，不向上游推送。

## 当前纳入的改动

- 随机播放队尾续接，以及移动端隐藏不支持的系统字体选择器（上游 PR #116）。
- DLNA 多网卡媒体代理路由（上游 PR #119）。
- 完整会话快照与播放进度恢复。
- 首页卡片透明度。
- 播放页独立图片背景、遮罩与模糊。

## 触发与下载

推送 `preview` 自动构建 Android、Windows、macOS，并尝试构建未签名 iOS 包。
分析与测试先运行；分析错误会阻断构建，现有警告与提示保留在日志中。
iOS 构建失败不阻断其他平台预览发布。

复用默认分支已有的 `build-validation.yml` 工作流路径，预览分支中的工作流名称为
`build-preview`，因此无需修改主分支即可手动选择 `preview` 运行：

```bash
gh workflow run build-validation.yml --repo qbmzc/FeiNiuMusic --ref preview
```

成功后在本仓库 Releases 中生成带 `Pre-release` 标识的预览版本，不替换正式版 Latest。
发布成功后自动删除本次 Actions 的中间 artifacts，安装包从 Release 下载。
未成功发布的 artifacts 最多保留 1 天；Release 下载文件长期保留。
Android 使用本仓库已有签名；macOS 包未公证；iOS 包需要自行签名。

## 版本

`pubspec.yaml` 的数字版本为 `1.6.9+1`。工作流统一生成：

- 应用内版本、Release tag、下载文件名：`1.6.9-preview.N`。
- 原生版本：`1.6.9`；构建号：源 build number + 工作流 run number。
- `N` 是此工作流的 `github.run_number`，后续构建递增；重跑同一次构建保留版本号。

通过 `APP_PREVIEW_VERSION` 编译参数显示预览标签，原生版本仍满足各平台数字格式要求。
预览构建沿用发布流程锁定的 Flutter commit，依赖按锁文件与指定 pub 镜像安装。

## 后续维护

1. 在功能分支开发并验证，提交后将所需改动合入 `preview`。
2. 更新本文的改动列表，再推送 `preview`；无需改动下游或上游主分支。
3. 同步新的上游版本时合并 `upstream/main`，处理冲突，更新源版本号以及工作流中的
   `PREVIEW_BASE_SHA`（预览说明生成的基准提交），重新验证。
4. 工作流有仓库与分支限制：仅在 `qbmzc/FeiNiuMusic` 的 `preview` 分支构建和发布。
